# VibeSB releases

Downloads for **VibeSB**, an all-in-one Hypixel SkyBlock mod for Fabric. This repository only holds the release jars; grab the latest from [Releases](https://github.com/jaymey248/VibeSB-releases/releases/latest).

## Install
1. Install **Fabric Loader** for your Minecraft version.
2. Put the VibeSB jar for your version in `.minecraft/mods` (`+26.1.2` for Minecraft 26.1.2, `+26.2` for 26.2).
3. Also put these required mods in `mods`: [Fabric API](https://modrinth.com/mod/fabric-api), [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin) and [Hypixel Mod API](https://modrinth.com/mod/hypixel-mod-api). [Mod Menu](https://modrinth.com/mod/modmenu) is optional.

Open the settings in game with **Right Shift**, `/vsb` or `/vibesb`. Almost every feature starts off.
